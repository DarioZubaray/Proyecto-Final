# Documentación (`docs/`)

Esta carpeta reúne material de documentación del trabajo final: **diagramas** en formato Mermaid y documentación de la cursada.

## Contenido

| Subcarpeta | Descripción |
|------------|-------------|
| [`diagramas/`](diagramas/) | Diagramas en formato [Mermaid](https://mermaid.js.org/): casos de uso, clases, entidad-relación y secuencias de login/logout. |
| [`MDS2/`](MDS2/) | Documentación de la materia **Metodologías de Desarrollo 2** (examen final). |

## Diagramas (`diagramas/`)

| Archivo | Descripción |
|---------|-------------|
| [`casos-uso.mmd`](diagramas/casos-uso.mmd) | Casos de uso por actor (Admin, Profesor, Alumno). |
| [`clases.mmd`](diagramas/clases.mmd) | Diagrama de clases con el patrón **Composite** de roles/permisos. |
| [`er.mmd`](diagramas/er.mmd) | Modelo entidad-relación de la base de datos. |
| [`secuencia-login.mmd`](diagramas/secuencia-login.mmd) | Secuencia del inicio de sesión (usa Singleton/Multiton, Composite y persistencia de preferencias). |
| [`secuencia-logout.mmd`](diagramas/secuencia-logout.mmd) | Secuencia del cierre de sesión: conserva el idioma y tema "último usado". |

Los archivos `.mmd` pueden visualizarse en **GitHub** (renderizado nativo de Mermaid) o con cualquier editor/visitor compatible.
