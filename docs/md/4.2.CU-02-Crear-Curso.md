#### 4.2.3. Objetivo

Permitir el alta de un nuevo curso en el sistema para que quede disponible en la oferta académica e inscripciones.

#### 4.2.4. Precondiciones

El usuario debe estar autenticado como Coordinador o Profesor.

El sistema debe contar con la lista de materias habilitadas para asociar.

#### 4.x.5. Puntos de Extensión y Condiciones

- Punto de Extensión: No aplica.

- Condición: Los datos ingresados cumplen las reglas de validación y el nombre no se encuentra registrado previamente.

4.2.6. Descripción analítica del Caso de Uso

1. El usuario selecciona la opción "Inscripciones" del menú "Académico".

2. El sistema muestra el formulario de Gestión de cursos.

3. El usuario ingresa el nombre del curso, descripción, fecha de inicio y fin, aula y hora de inicio y fin, y profesor a cargo.

4. El usuario presiona el botón "Guardar".

5. El sistema valida los datos requeridos y verifica que el profesor no se encuentre dictando clases en el mismo dia y horario.

6. El sistema persiste el nuevo curso en la base de datos.

7. El sistema confirma la operación mediante un mensaje de éxito y actualiza la lista de cursos.

Flujos Alternativos:

4.a Datos incompletos o inválidos:
	1-El sistema detecta que faltan campos obligatorios o que el cupo es un valor no válido.
	2-El sistema muestra un mensaje de advertencia indicando los errores.
	3-El usuario corrige los datos y vuelve a presionar "Guardar".

#### 4.2.7. Modelo de Dominio
Participan las siguientes entidades:
	- Curso
	- Materia
	- Profesor
	- Coordinador
