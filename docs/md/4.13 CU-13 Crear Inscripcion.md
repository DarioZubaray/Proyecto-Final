#### 4.13.3. Objetivo

Registrar la inscripción de un alumno a un curso, dejándolo matriculado oficialmente en la oferta académica vigente.

#### 4.13.4. Precondiciones

- El usuario ha iniciado sesión como Coordinador.
- Existen alumnos registrados en el sistema.
- Existen cursos activos con horario definido (día y hora de inicio y fin).

#### 4.13.5. Puntos de Extensión y Condiciones

- **Punto de Extensión:** No aplica.
- **Condición:** El alumno no se encuentra inscripto en el curso y no tiene traslape de horario con otra inscripción vigente.

#### 4.13.6. Descripción analítica del Caso de Uso

**Campos que completa el usuario:**

| Campo | Tipo | Obligatorio | Validación |
| :--- | :--- | :--- | :--- |
| Alumno a inscribir | Lista desplegable | Sí | Debe seleccionarse un alumno. |
| Curso | Lista desplegable | Sí | Debe seleccionarse un curso; el curso debe existir, estar activo y tener horario definido. |

Flujo Básico:
1. El usuario accede al formulario "Gestión de Inscripciones" del menú "Académico".
2. El sistema muestra las listas de alumnos y de cursos activos, la grilla de inscripciones vigentes y el campo de búsqueda.
3. El usuario selecciona el campo "Alumno a inscribir".
4. El usuario selecciona el campo "Curso".
5. El usuario presiona el botón "Inscribir alumno".
6. El sistema muestra la confirmación "¿Desea inscribir a '\<alumno\>' en el curso '\<curso\>'?"
7. El usuario presiona "Sí".
8. El sistema muestra el mensaje "Inscripción realizada exitosamente." y actualiza la grilla con la nueva inscripción.
9. Fin del Caso de Uso.

Flujos Alternativos:
- **5.a Alumno no seleccionado:**
  1. El sistema muestra el mensaje "Seleccione un alumno para inscribir."
  2. El usuario selecciona el campo "Alumno a inscribir" y vuelve a presionar "Inscribir alumno".
- **5.b Curso no seleccionado:**
  1. El sistema muestra el mensaje "Debe seleccionar un curso."
  2. El usuario selecciona el campo "Curso" y vuelve a presionar "Inscribir alumno".
- **7.a El usuario cancela la confirmación:**
  1. El usuario presiona "No".
  2. El sistema no realiza ningún cambio y permanece en el formulario (fin del intento).
- **7.b Alumno ya inscripto en el curso:**
  1. El sistema muestra el mensaje "Ya está inscripto en este curso."
  2. El usuario selecciona otro curso o cancela la operación.
- **7.c Curso inexistente o inactivo:**
  1. El sistema muestra el mensaje "El curso seleccionado no existe."
  2. El usuario selecciona otro curso y vuelve a inscribir.
- **7.d Curso sin horario definido:**
  1. El sistema muestra el mensaje "El curso seleccionado no tiene horario definido."
  2. El usuario selecciona otro curso y vuelve a inscribir.
- **7.e Traslape de horario con otra inscripción vigente:**
  1. El sistema muestra el mensaje "Tiene traslape de horario con el curso '\<curso\>' (\<día\> \<hora inicio\> - \<hora fin\>)."
  2. El usuario selecciona otro curso sin traslape o cancela la operación.
