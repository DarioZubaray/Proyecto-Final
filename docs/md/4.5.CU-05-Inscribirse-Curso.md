#### 4.5.3. Objetivo

Permitir que un alumno quede matriculado oficialmente en un curso elegido de la oferta académica actual.
#### 4.5.4. Precondiciones

- El alumno ha iniciado sesión en el sistema.
    
- Existen cursos en estado activo y con periodo de inscripción abierto.
#### 4.5.5. Puntos de Extensión y Condiciones

- **Punto de Extensión:** No aplica.
    
- **Condición:** Existencia de vacantes en el curso y sin sobreposición con otros cursos inscriptos.
#### 4.5.6. Descripción analítica del Caso de Uso

1. El Alumno ingresa al formulario "Inscripciones" del menú "Académico".
    
2. El sistema lista todos los cursos vigentes que cuentan con cupos disponibles.
    
3. El Alumno selecciona el curso deseado y presiona el botón "Inscribirse".
    
4. El sistema verifica que el alumno no esté inscripto previamente en ese mismo curso.
    
5. El sistema comprueba la disponibilidad del cupo en tiempo real.
    
6. El sistema crea el registro de inscripción y descuenta un lugar del cupo del curso.
    
7. El sistema confirma la inscripción en pantalla mediante un mensaje de éxito.

**Flujos Alternativos:**

- **4.a Cupo agotado:**
    
    1. Al intentar guardar la inscripción, el sistema detecta que el cupo se ha completado.
        
    2. El sistema notifica: "Sin cupo disponible para el curso seleccionado".
        
    3. Finaliza el flujo sin realizar la inscripción.
        
- **4.b Alumno ya inscripto:**
    
    1. El sistema verifica que el alumno ya posee una inscripción activa en dicho curso.
        
    2. El sistema despliega el mensaje: "Ya te encuentras inscripto en este curso".
        
    3. Se interrumpe la inscripción.
